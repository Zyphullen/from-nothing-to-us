    All 118 elements: where they come from

    Each box = one element (Z = number of protons). Colour = main cosmic source. Small dots = other sources. Tap one for details.
    Tap an element.
    Origins follow Jennifer Johnson's "nucleosynthesis periodic table" (Science 2019; SDSS chart), simplified to main and secondary sources for Solar System matter. Shares are estimates and still debated, especially how much of the heaviest elements come from neutron-star crashes versus rare kinds of supernova. 94 elements occur in nature (Tc, Pm, Np, Pu only in traces). 95–118 have only been made in labs; 113, 115, 117 and 118 were named in 2016 (IUPAC).
